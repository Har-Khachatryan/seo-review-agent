## Needs attention

1. **Sitemap pages return a server error** (critical, new)
   - Why: Two indexable sitemap URLs fail to answer, so search engines and AI crawlers may drop them or waste crawl budget on dead pages.
   - Next step: Developers should check the server or application logs for these two URLs, restore them to HTTP 200, and re-crawl to confirm.
   - https://www.searchbloom.com/blog/best-personal-branding-websites-for-ceos/

   - Why: Three live pages link to 404 URLs, creating dead ends for visitors and crawlers and wasting link equity.
   - Next step: Content editors should update the links on the three source pages to working URLs, or developers should add 301 redirects from the dead URLs.
