# SEO review: searchbloom.com, 2026-11-24

**Status:** AMBER · The site is up and crawlable with good real-user speed, but three broken internal links and several on-page gaps need fixing.

## Needs attention

1. **Broken internal links point to 404 pages** (high)
   - Why: Three live pages link to dead URLs, creating dead ends for visitors and crawlers and wasting internal link equity.
   - Next step: Content editors should update the links on the source posts, or the SEO or dev team should add redirects from the dead URLs to the right pages.
   - https://www.searchbloom.com/blog/3-easy-tips-to-creating-content-people-will-share/
   - https://www.searchbloom.com/blog/4-old-school-seo-tactics-to-stop-now/
   - https://www.searchbloom.com/blog/landing-pages-for-events/
2. **Lab page speed slow on generative-engine-optimization page** (medium, new)
   - Why: Lab LCP median was 4129 ms, and individual runs ranged from 2535 ms to 10673 ms, with no real-user data for this page.
   - Next step: Developers should check the largest element and image weight on this page and re-test, and should not treat one run as a trend.
   - https://www.searchbloom.com/generative-engine-optimization/
3. **Lab LCP slow on several key pages** (medium)
   - Why: Lab LCP reached 11025 ms on the answer-engine page and 10465 ms on the best-AI-agencies strategy page, with no real-user data for either.
   - Next step: Developers should review hero images, scripts and render-blocking resources on these pages, then re-run PageSpeed to confirm the pattern holds across runs.
   - https://www.searchbloom.com/answer-engine-optimization/
   - https://www.searchbloom.com/strategy/best-ai-seo-agency-companies-services-usa/
   - https://www.searchbloom.com/ecommerce-seo/
4. **Pages without a meta description** (medium)
   - Why: Eight pages, including a sitemap, a case study and several team pages, have no meta description, so search engines write their own snippets.
   - Next step: Content editors should add unique descriptions to these pages, starting with the team bios and the case study.
   - https://www.searchbloom.com/sitemap/

5. **Pages without an H1 heading** (medium)
   - Why: Seven key hub pages, including Team, Tools, Strategy and Contact, have no H1, which weakens the page topic signal for search and AI systems.
   - Next step: Content or dev team should add one clear H1 to each template or page, matching the page's main topic.
